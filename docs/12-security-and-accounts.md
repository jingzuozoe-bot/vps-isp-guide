# 安全、云服务会员与账号资格

目的：把网络配置与目标服务订阅分清。

ISP 出口并不改变你的实际所在地，也不代替目标服务的地区、身份、支付和用途要求。订阅 Claude、其他 AI 或任何云服务前，由 Agent 检查该服务当前官方支持地区和条款，用户如实填写信息并自行决定付款。不提供伪造身份、支付或规避限制的步骤。

网络顺序应是：先完成不含账号的链路检查，再确认官方资格，然后订阅/登录目标应用，再验证应用真实请求。不要先交年费再发现线路或资格不满足。

## 凭据最少暴露

- 私钥留在设备；公钥才上传 VPS。主机指纹从独立可信渠道核对。
- 密码只在本地受限配置填写，避免命令行、聊天、截图和日志。
- 仅本机用的代理绑定 127.0.0.1；不开放未认证公网代理。
- 白名单只添加真实需要的源地址；撤销前核其他订单是否共享该列表。
- 网站继续用 HTTPS；SOCKS5 和“HTTP/HTTPS 代理”营销名不自动代表代理传输有 TLS。
- 对秘密泄露先撤销/轮换，再清理副本与 Git 历史。私有仓库也不是理想密码库。

## 应用数据清理不是默认安装步骤

旧登录迁移需要先盘点具体对象、退出应用、备份与核验，再逐项处理。不要让 Agent 删除整个主目录、钥匙串、浏览器资料或项目。清缓存不能抹去服务端记录，也不能保证账号不会受限。
