# 日常使用、续费和维护

目的：避免配置好后因到期、凭据变化或更新失效。

## 每次使用

先确认本次客户端和隧道状态，用无敏感内容的 HTTPS 请求核出口，再启动需要指定出口的应用。异常时先停相关应用，再诊断或按恢复卡回原网。

## 续费前

记录 VPS 和 ISP 各自到期日、时区、币种、真实续费金额、自动续费和取消入口。想保留地址时提前核原 IP 是否续留、是否启用续费换新。保留提醒，但本库不自动代付或创建定时任务。

## 成本计算

```text
首次现金支出 = VPS 实际预付周期总额 + ISP 实际预付周期总额
             + 客户端费用 + 税费/支付费 + 经确认的附加选项
日常月均预算 = 各项周期总额按实际周期折算（只是预算，不是首付款）
```

VPS 和 ISP 都可能有流量/公平使用限制。转发带来两条连接，供应商如何计算入站/出站以各自政策为准；别假设用户下载量等于账单流量。

## 更新软件或配置

固定当前版本并保存可恢复配置；从官方发行渠道下载并按发布方提供的签名/校验方式验证。一次只更新一个组件。先语法，再真实出口，再相关故障与恢复检查；不自动下载未知脚本执行。

## 不用了

先停业务应用，恢复原网络，只停新增隧道和新客户端入口；核对 VPS 上本次专用组件，避免删除别的业务。随后本人决定取消哪些服务续费、撤销白名单/凭据和销毁哪些副本。取消服务前导出需要的资料，不把退款当数据备份。
