核验日：2026-11-10。这两处是公开检测站，不是供应商，也不证明账号资格。只用来对照 C03a。不转载分数段、检测截图或某次查询结果。一家的标记不能单独决定通过或失败。

| 来源 | 支持什么判断 |

| [Ping0](https://ping0.cc/) | 公开的类型、原生/广播与风控查询 |
| [Ping0 常见说明](https://ping0.cc/ip/faq) | 站点自己的口径：机房按网段用途而不是所有者名称；广播指注册地国家与当前定位国家不一致，或网段被拿到另一地宣告使用 |

采购建议和起步硬件规格是本库的工程判断，非商家承诺。文档审阅、合成示例检查、真实设备实测是不同证据等级。

新增供应商前必须补官方商品、条款、计费、认证和续费来源；没核过就写待核，不把论坛促销帖当官方保证。
