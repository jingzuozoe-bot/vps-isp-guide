# 三分钟看懂

把 VPS 想成中转站，把 ISP 想成最后的出口门牌。你通过加密通道去中转站，再由它连接 ISP 代理，网站看到的是后者的出口。

| 词 | 白话 | 常见误解 |
|---|---|---|
| VPS | 你租的一台远程 Linux 电脑 | 买它不等于买到了住宅出口 |
| ISP 代理 | 最后一跳使用 ISP 地址的代理服务 | 不必是某户家里的实体宽带 |
| 静态 | 服务约定期限内保持地址 | 不等于永久不会变 |
| 独享 | 商家约定该代理分配给你 | 不等于没有历史使用记录 |
| SOCKS5 / HTTP | 软件和代理交流的协议 | SOCKS5 本身不提供传输加密 |
| 系统代理 | 告诉愿意遵守的应用使用代理 | 不等于强制接管所有应用 |
| TUN | 在系统网络层接管流量的一类方式 | 开启不等于已经消除泄漏 |
| 配置文件 | 客户端读的设置 | 可能含密码 |
| 订阅 URL | 能下载配置的地址 | 持有链接的人可能拿到凭据 |
| 故障停连 | 指定链路失效时受保护流量停止 | 连接自动恢复不证明中途没有旁路 |
| Cloud / 云服务订阅 | 可能指 VPS、代理套餐或目标应用会员 | 三者分开购买和验收 |

第一段加密不代表每一段都加密。SSH 保护设备到 VPS；VPS 到 ISP 若是普通 SOCKS5，代理认证和目标元数据仍可能可见。访问网站继续使用 HTTPS，且不要关闭证书检查。需要整段代理传输加密时，须另选上游明确支持的加密接入并验证。
