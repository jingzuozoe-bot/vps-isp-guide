# 买什么，怎么买，哪些坑先避开

目的：用最少资源验证完整链路，避免把长期套餐、轮换 IP 或高价线路当作配置前提。你已有可用资源就跳过购买。

## 推荐的起步组合

**一台 Linux VPS + 一个独享静态 ISP IP + 一个官方来源客户端。先短周期，验证后再续。**

下面规格是本库对轻量个人 TCP 中转的起步建议，不是性能保证或商家最低要求：1 vCPU、约 1GB RAM、10–20GB 磁盘即可作为候选；实际按系统、并发和监控开销调整。重点比较你到 VPS 的路由与 VPS 到 ISP 的质量，而不是堆内存。

## 搬瓦工：看线路和机房，再看套餐大小

在 [官方商品页](https://bandwagonhost.com/vps-hosting.php) 选自管理 KVM Linux VPS。可用系统和套餐以页面为准。Debian/Ubuntu 的受支持稳定版本便于 Agent 维护；先核架构和软件兼容。

| 选择 | 什么时候考虑 | 付款前要核什么 |
|---|---|---|
| 普通 KVM 线路 | 你的本地网络到机房已经稳定 | 晚高峰、丢包、可用 IPv4、流量与限速 |
| CN2 GIA 等优化线路 | 本地到普通线路实际质量差 | 是否改善你的运营商和时段，不能只看品牌词 |
| 洛杉矶等美国机房 | 最终目标和 ISP 在美国时作候选 | 本地→机房和机房→ISP 两段都要考虑 |
| 新加坡等机房 | 你到当地接入更适合时作候选 | 最终 ISP 地区应按业务许可和实测选择 |

不要照搬旧促销 SKU 或把年付折算月价当成首付款。本库不固定某个搬瓦工价格：当前目录与库存会变，Agent 应打开 [官方机器可读目录](https://bandwagonhost.com/order/catalog.json)，再和结算摘要逐项核对。

搬瓦工是自管理服务，系统维护由你承担。退款有多项前提，且官方条款写明获准退款会终止账户下全部服务并删除数据/快照。先备份、核适用范围，不能当无风险试用。见 [官方条款](https://bandwagonhost.com/terms-of-service.php)。

## IPRoyal：选 ISP，不要误选 Residential 轮换池

| 页面类型 | 是否适合固定出口目标 |
|---|---|
| ISP / Static Residential / Dedicated | 首选候选；核固定期、独享和续费保 IP |
| Residential 按 GB 的轮换池 | 不作为本库固定地址路线的替代 |
| Sticky session | 粘性时段不等于长期固定分配 |
| Datacenter | 机房代理，不替代 ISP 产品属性 |
| Mobile | 移动代理，购买与地址行为另议 |

首次建议一个 IP，先 1 天（有库存时）或 30 天。短期试用与长期保 IP 要分别核对，不假定换周期自动保留原地址。官方价页在 2026-10-25 显示 24 小时 $1.80/IP 起、30 天 $2.70/IP 起；60/90 天显示的 $2.55/$2.40 是页面起价口径，**不能直接当整期应付总额**。地区、附加选项、税费和实际周期总额以订单为准。[价格页](https://iproyal.com/pricing/static-residential-proxies/)

认证可用用户名/密码或源 IP 白名单。本路线白名单填 **VPS 实际公网出站 IP**，不是家里地址或 ISP 出口本身。按订单确认权限范围，现有白名单不要整表覆盖。[ISP 文档](https://docs.iproyal.com/proxies/isp)

“无限流量”仍受公平使用约束；核高速额度和超额后的速度。多设备、续费换新 IP 以及附加筛选可能影响订单：想保留地址时不要盲开每次续费换新地址。具体策略和入口以当前后台为准。[官方购买与管理指南](https://iproyal.com/quick-start-guides/static-residential-proxies/)

## 其他供应商也用同一张表

Surflare 等只作为可比较候选；尚未在本版本重新核验其价格与规则，不填旧报价冒充现价。问清“单买 ISP 代理是否可用、是否另需基础会员”。任何替代商都逐项填 [订单模板](../templates/order-review.md)。

## 付款前最后八项

1. 商品类型、地区、独享/共享、地址保持期限。
2. 真实首付款、币种、税费、支付费与续费总价。
3. 计费周期、自动续费、取消入口、到期地址释放和更换规则。
4. VPS 的带宽、月流量、超额处理、控制台和快照能力。
5. ISP 的协议、端口、认证、VPS 接入与多设备使用许可。
6. TCP/UDP、IPv6、认证传输是否加密，别根据 SOCKS5 名称推断。
7. 退款时限、流量门槛、适用产品，向客服确认歧义。
8. 目标云服务是否允许你的实际所在地和用途；出口不代替资格。

**Agent 可以核对和整理订单；付款由用户明确决定。** 下一步：[开工](03-quickstart.md)。
