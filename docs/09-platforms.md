# 支持范围：平台不是复制粘贴就能通用

| 平台/路线 | 本库提供 | 当前公开验证等级 |
|---|---|---|
| macOS + OpenSSH + ISP SOCKS5 | TCP 局部参考步骤、配置占位模板 | 文档审阅；未做本版本干净环境端到端认证 |
| Linux 电脑 + OpenSSH | 同一路线，发行版差异由 Agent 核对 | 参考，未认证 |
| Linux VPS | SSH 转发和上游独立验证思路 | 不含自动加固安装器 |
| Mihomo 客户端 | 唯一 SOCKS 出站候选 YAML | 仅候选；依实际核心版本校验 |
| Windows | 采购/验收/恢复原则 | 未提供完整适配，需核 OpenSSH 与系统设置 |
| iOS / Android | 独立接入、锁屏/换网检查清单 | 未提供可直接部署的手机加密入口配置 |
| 热点/USB | 隔离诊断原则 | 不作固定出口的必要条件或安全保证 |
| 系统级故障停连 | 需求、失败教训和放行门槛 | 未提供生产实现 |

## 手机后续适配必须补什么

手机支持的加密协议、VPS 监听与认证、唯一 ISP 出站、配置导入/撤销、DNS/IPv6/UDP、客户端退出、蜂窝/Wi-Fi 切换、锁屏、重连窗口，以及热点电脑单独验收。仅有 ISP SOCKS5 参数不足以证明本地→VPS 加密链路成立。

贡献者提交适配时填写 [设备报告](../templates/platform-report.md)：版本、网络条件、配置结构、测试范围、故障证据、恢复证据。没有这些不提升“已验证”标记。

详细步骤见 [手机适配路线](14-mobile-roadmap.md)。历史手机导入失败仍未解决，不作为可用配置发布。
